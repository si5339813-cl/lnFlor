## Важно про логотип
Положите оригинальный `group3.png` в ту же папку, где находится `index.html`. В переданных материалах сам файл `group3.png` не обнаружен, поэтому в архив не удалось встроить оригинальный логотип. Пока его нет, отображается запасной знак «ЛФ».

## Запуск
```bash
python server.py
```
Откройте http://localhost:8000 и обновите страницу через Ctrl+F5.
